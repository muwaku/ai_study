# Learning Progress Sync

`progress.json` is generated by the local learning assistant.

It stores browser-side learning state so another device can continue from the
same lesson:

- current lesson index
- completed lessons
- per-lesson chat history
- per-lesson knowledge points
- review notes generated when a lesson is ended

Use the page button `同步到 Git` to sync manually. The page also attempts to sync
automatically when `结束今天并保存进度` is clicked.

Do not store API keys or credentials in this directory.
