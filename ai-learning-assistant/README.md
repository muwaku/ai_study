# AI 学习助手入口

双击仓库根目录的 `开始学习.bat`。它会启动本地服务并打开学习页面。需要停止后台服务时，双击 `停止学习助手.bat`。

使用方式：

1. 首次使用时，在页面里填写 OpenAI API Key 并保存。
2. 点击“开始/继续学习”，页面会自动把当前进度注入给 AI。
3. 在页面内和学习助手对话，按它安排学习和练习。
4. 完成练习后，在“提交验收”里填写文件或目录路径、命令输出、你的说明。
5. AI 按当前课程通过标准验收；通过后页面会自动进入下一次学习。

API Key 保存在 `ai-learning-assistant/.env.local`，该文件已被 `.gitignore` 忽略。

进度和对话保存在浏览器 localStorage 里。需要换浏览器或换电脑时，用页面里的“导出进度”和“导入进度”。
