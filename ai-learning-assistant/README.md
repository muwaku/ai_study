# AI 学习助手入口

双击仓库根目录的 `开始学习.bat`。它会启动本地服务并打开学习页面。需要停止后台服务时，双击 `停止学习助手.bat`。

默认调用本机已登录的 `codex-openai` / `codex` 命令交互，不需要单独配置 OpenAI API Key。

使用方式：
1. 先看页面上方的“学习计划”。“本题知识点”会由 AI 根据当前练习自动写入，不是教材原文。
2. 点击“开始/继续学习”，对话框只会给当前任务、解释命令、处理你的运行结果和疑问。
3. 在页面内和学习助手对话，按它安排学习和练习。
4. 完成练习后，在“提交验收”里填写文件或目录路径、命令输出和你的说明。
5. Codex 会按当前课程通过标准验收；通过后页面自动进入下一次学习。
6. 复习时看页面右侧“复习笔记”。学习过程中可以手动保存笔记，也可以点“保存最近 AI 回复”把 AI 的复习卡片保存下来。

如果本机找不到 `codex-openai` / `codex`，页面会退回到手动模式：复制提示词并打开 ChatGPT 网页。也可以在页面里展开“API 设置”，填入 OpenAI API Key 作为备用。

API Key 如有配置，会保存在 `ai-learning-assistant/.env.local`，该文件已被 `.gitignore` 忽略。

进度和对话保存在浏览器 localStorage 里。需要换浏览器或换电脑时，用页面里的“导出进度”和“导入进度”。
